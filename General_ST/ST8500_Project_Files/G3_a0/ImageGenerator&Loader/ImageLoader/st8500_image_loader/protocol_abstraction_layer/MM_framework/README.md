## Package Content

This package contains the MM Framework.
This framework is useful for building a host application based on the MM protocol.
	
This software is compatible with ST8500 and ST75MM.
A direct serial communication between the PC and the platform is required (if using an evaluation kit, make sure it is running in "passthrough mode").
	
## Info

The MMinterface class is used as control interface to send requests and receive confirms or indications from the platform.

## Usage

Import the "mm_protocol" module and use "MMinterface" to create a controller for the MM protocol.
