# PowerMesh: PLC Home Digital PCB

This folder contains information related to the digital parts of the PLC hub board; more specifically the non coupler circuitry.

## Files
- `Digital_Board` contains the KiCad design files for Schematic and PCB layout
- `General_ST_Docs` contains ST chip information that would be useful to navigate the project
- `Programming_Docs`: Programming Docs on how to program the chip
